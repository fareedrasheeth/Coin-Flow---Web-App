# Coin-Flow - Web App

A modern Web App for our smart coin sorter & hardware detector project built with Next.js, React, Tailwind CSS, Framer Motion, and Firebase / MQTT integration.

## Features

- **Dashboard**: Live telemetry tracking total coins, total savings breakdown (LKR 1, 2, 5, 10), and real-time activity feeds.
- **Interactive Coin Slots**: Visual representations of each coin slot with capacity bars and coin drop animations.
- **Analytics**: Comprehensive visual breakdown of coin accumulation trends.
- **Map View**: Location tracking for smart coin detector hardware units.
- **Rewards**: Gamified milestone achievements and savings goals.
- **Health Diagnostics**: Real-time hardware device status and sensor telemetry.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
